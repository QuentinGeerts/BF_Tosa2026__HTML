4. Quoi utiliser quand ?

La règle simple: - flex pour une dimension (ligne OU colonne) - grid pour deux dimensions (lignes ET colonnes)

Besoin Règles CSS Exemples
Aligner des éléments sur une ligne ou une colonne display: flex Menu, barre de boutons, logo + liens
Centrer un élément display:flex Message au milieu d'un bloc
Des éléments de tailles variable qui passent à la ligne display: flex + flex-wrap Liste
Organiser en lignes ET en colonnes display: grid Galerie de photos, catalogue de produits
Mettre en page tout la page display: grid + grid-template-areas header / aside / main / footer
Placer un élément par-dessus un autre position: absolute dans un parent relative Badge sur une image, icône dans un champ
Garder un élément visible à l'écran position: fixed Bouton "Haut de la page", bandeau de cookie
Garder un élément visible pendant le défilement de sa zone position: sticky En-tête de tableau, menu qui reste en haut, ...
